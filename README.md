# Obsidian Knowledge System · 个人知识整理与检索

把资料整理成可复用的 Wiki，再让 AI 带着来源回答。包括原有 Raw/Wiki 整理方法、本机关键词与向量检索、Obsidian 插件、MCP Agent 接口，以及情绪日记回顾提示词。

**这是可运行、仍有已知限制的本机项目。** Skill 是操作说明，Python 是检索服务，Obsidian 插件负责搜索与来源定位，Claudian 或其他 MCP 客户端负责模型对话。安装 Skill 不会自动装好其他部分。

## 工作原理

```text
明确要求保存的材料 → Raw 不变来源 → Wiki 知识页与链接
                                          ↓
允许目录里的 MD/TXT → SQLite 关键词 + 本机 BGE 向量
                                          ↓
Agent 锁定范围、分项检索、读正文 → 来源核对 → 回答与原文链接
```

日记可以直接写在允许的个人记录目录，不必每篇先变成 Wiki。服务检查变化，构建并验证新索引后发布；未变的向量输入可复用。原始笔记是数据源，向量不是对模型的训练。

## 功能与边界

- 关键词、语义、混合检索；按文件、集合与日期范围研究；记录实际读过的范围。
- 新增、修改、删除和重命名后更新派生索引；失败保留上个可用版本。
- 短来源链接与 Obsidian 原文定位；引用变动或失效时不冒充精确定位。
- 情绪表达区分倾诉、回顾、分析、建议；保留反复，避免强行写成成长故事。
- 引文核对不保证 AI 的解释正确；附件正文未自动纳入；不是全库无遗漏搜索。

## 公开版本内容

只包含筛选后的代码、合成测试、通用提示、规则模板与 Skill。没有个人 Vault、真实检索样本、运行日志、索引、模型权重、账户配置或私人 Git 历史。默认路径已改成当前用户的 `~/Documents/Obsidian`；实际建库与 MCP 配置仍应明确指定路径。

默认允许目录为 `wiki`、`我的存在`、`世界知识`、`运动健身（大学）`、`计算机和AI`、`英语`、`图谱索引`。这是现有实现的目录约定，尚无通用目录配置界面。先用示例结构或审查适配源码，不要以为所有目录都会自动入库。

Python 3.11；插件构建需支持直接运行 TypeScript 测试的 Node（推荐 Node 22.18+）。核心通过 localhost 和 stdio 通信，托管脚本为 macOS launchd。未验证完整 Windows/Linux 安装。

## 模型与数据

Embedding 使用本机 `BAAI/bge-small-zh-v1.5`，固定版本见 `embedding-model.json`。对话沿用 MCP 客户端自己的模型与认证；客户端调用工具后，返回的片段可能被发送给其模型提供商，因此“检索在本机”不等于“回答全程离线”。旧网页问答入口仅适配 DeepSeek 官方 API，密钥在该服务内存中。
